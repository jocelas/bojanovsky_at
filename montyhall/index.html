Monty Hall Problem Simulation

This is a (generalized) Monty Hallo problem simulator. It gives a plot for the sucess rate when switching and not switching your initial guess.
First, a random door is chosen, then a chosen number of empty doors is opened. After that, the initial guess is switched to a different, random, door (excluding the initially chosen one). The graph shows the success rate with a higher number of runs.









Error: The number of opened doors must be less than the number of empty doors!
